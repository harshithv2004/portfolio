
# portfolio
# 🚀 Harshit Veerapur — Personal Portfolio Website

A modern, high-performance portfolio website built with **React**, **Vite**, **Tailwind CSS**, and **Framer Motion**, engineered specifically for seamless deployment to **Vercel**.

---

## ✨ Features

- 🌌 **Smooth Animations & Micro-Interactions**: Ambient glowing meshes, Framer Motion reveal animations, particle physics, and confetti celebration effects.
- 💼 **Complete GitHub Project Showcase**: Automatically curated with all 14 projects from GitHub (`@harshithv2004`) including:
  - **Insurance Claims Processing Agent** (FNOL AI Pipeline)
  - **InsightBoard** (Flask & MySQL SQL Analytics Dashboard)
  - **SLM** (Small Language Model architecture & training)
  - **StegnoChat** (Covert steganographic encrypted chat)
  - **Resume Analyser** (NLP ATS matching & scoring)
  - **Pathfinder** (Algorithm visualizer in TypeScript)
  - **Text Summarizer**, **Customer Churn Predictor**, **EV Range Calculator**, and more.
- 📊 **Architecture Deep Dive Spotlight**: Interactive tabbed code showcase highlighting complex SQL CTEs, MySQL window functions (`LAG`), and Python data pipelines.
- 🔍 **Interactive Filtering & Search**: Instant real-time search across projects by title, category, and tech stack tags.
- 📱 **100% Responsive Design**: Tailored for mobile phones, tablets, and desktop displays.
- ⚡ **Instant Email Contact & Copy**: Working contact form that addresses inquiries directly to `harshitveerapur4@gmail.com` with one-click copy and toast notifications.

---

## 🛠️ Tech Stack

- **Framework**: React 18 + Vite 6
- **Styling**: Tailwind CSS
- **Animations**: Framer Motion
- **Icons**: Lucide React
- **Effects**: Canvas Confetti
- **Deployment**: Vercel (pre-configured with `vercel.json`)

## 🚀 How to Deploy to Vercel

### Option 1: Deploy via GitHub (Recommended)

1. Initialize a git repository inside the `portfolio` folder (or push this repo to GitHub):
   ```bash
   cd portfolio
   git init
   git add .
   git commit -m "Initial portfolio commit"
   ```
2. Create a new repository on your GitHub account (`https://github.com/new`), for example `portfolio`.
3. Push your code:
   ```bash
   git remote add origin https://github.com/harshithv2004/portfolio.git
   git branch -M main
   git push -u origin main
   ```
4. Go to [vercel.com](https://vercel.com) and log in with your GitHub account.
5. Click **"Add New..."** &rarr; **"Project"**.
6. Import your `portfolio` repository. Vercel automatically detects **Vite** settings:
   - **Framework Preset**: Vite
   - **Build Command**: `npm run build`
   - **Output Directory**: `dist`
7. Click **"Deploy"**! In ~30 seconds, your portfolio will be live at `https://your-portfolio.vercel.app`.

---

### Option 2: Deploy via Vercel CLI

Run this command in the `portfolio` folder:
```bash
cd portfolio
npx vercel
```
Follow the quick CLI prompts to link to your Vercel account and deploy immediately!

1. Build the production files:
